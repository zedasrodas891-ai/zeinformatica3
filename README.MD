# 📱 Simulador de Orçamento - Assistência Técnica de Celulares

Aplicação web interativa desenvolvida em **Python** e **Streamlit** para permitir que clientes simulem orçamentos de manutenção de smartphones (telas, baterias, placas de carga e tampas) de forma rápida, transparente e sob encomenda.

## 🚀 Funcionalidades Principais

- **Seleção Dinâmica por Categoria:** Navegação entre diferentes tipos de serviços e componentes.
- **Filtragem Inteligente:** Remoção automática de peças de baixa qualidade (Incell) na categoria de telas para garantir um padrão superior.
- **Precificação Oculta Integrada:** Embutimento transparente de taxas operacionais (mão de obra + frete do fornecedor) de forma invisível ao cliente final.
- **Modelo de Trabalho Sob Encomenda:** Avisos claros sobre a modalidade de pedidos para proteger o caixa e alinhar prazos.
- **Integração com WhatsApp:** Geração automática de link com o resumo completo do orçamento formatado para contato direto via WhatsApp.

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- **Streamlit**
- **JSON** (para gestão estruturada da tabela de preços)
- **HTML / CSS** (personalização visual de componentes)
